# Security Policy

## Supported versions

Security fixes are provided for the latest release only. Please update to the newest version before reporting an issue.

| Version        | Supported |
| -------------- | --------- |
| Latest release | ✅        |
| Older releases | ❌        |

## Reporting a vulnerability

If you find a security issue in Knome Workspace Switcher, please report it using one of these:

- **[Open an issue](https://github.com/sakibreza229/org.kde.plasma.knomeworkspaces/issues/new)**: for a specific, reproducible problem
- **[Start a discussion](https://github.com/sakibreza229/org.kde.plasma.knomeworkspaces/discussions)**: if you're unsure whether something is a security problem

Please include:

- A description of the issue and its potential impact
- Steps to reproduce
- Widget version, Plasma version, and distro

Since reports are public, please describe the problem clearly but avoid posting a ready-to-use exploit.

## What to expect

This is a small, volunteer-maintained project. Reports will be read and triaged as soon as possible, and confirmed issues will be fixed in a new release and noted in the changelog.

## Scope

This policy covers the code in this repository. Vulnerabilities in KDE Plasma, Qt, or other upstream components should be reported to those projects directly.
